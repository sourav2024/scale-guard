# Support

| I want to… | Go here |
| --- | --- |
| Understand or set it up | [README](README.md) |
| Report a wrong diagnosis | [Wrong diagnosis](https://github.com/sourav2024/scale-guard/issues/new?template=wrong_diagnosis.yml) |
| Report a script/CLI bug | [Bug report](https://github.com/sourav2024/scale-guard/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request](https://github.com/sourav2024/scale-guard/issues/new?template=feature_request.yml) |
| Ask a question | [Discussions](https://github.com/sourav2024/scale-guard/discussions) |
| Report a vulnerability | [Private advisory](https://github.com/sourav2024/scale-guard/security/advisories/new) — **not** an issue |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

**Redact before posting.** Issues are public: remove hostnames, credentials, company and customer names, and raw query literals.

This is a volunteer-maintained project. Issues are usually triaged within about a week. No commercial support is offered; the project is MIT-licensed, so you are free to fork it.
